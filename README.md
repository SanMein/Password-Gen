# Password-Gen V4

Генератор паролей из запоминаемых сегментов и случайной части. Один HTML-файл.

## Возможности
- Интерфейс RU / EN.
- Индекс и название проекта – leet-подстановка, запоминаемые сегменты.
- Случайная часть длиной 5–25 символов.
- Настраиваемый набор: заглавные, цифры, спецсимволы.
- Версия пароля (V1, V2, …).
- Сегменты перемешиваются и соединяются через `-`.
- Оценка стойкости: энтропия в битах и время перебора.
- Копирование в буфер, история на 10 паролей (только сессия).

## Схема пароля
1. `site_code` – индекс проекта, leet, до 4 символов.
2. `name_code` – название проекта, leet, до 4 символов.
3. `random_code` – случайная последовательность заданной длины.
4. `version_code` – `V{версия}`.
5. Сегменты перемешиваются и склеиваются через `-`.

Leet: `A→4, S→$, E→3, O→0, I→1, T→7`.

Случайность – `crypto.getRandomValues` с отбраковкой (без смещения по модулю).

## Запуск
Открыть `index.html` в браузере. Сборка и установка не нужны.

## Стек
- HTML + CSS + ванильный JS.
- Шрифты Inter, JetBrains Mono – fontsource через CDN.

## Приватность
Пароли создаются и хранятся только в памяти страницы. Сетевых запросов нет, история не пишется в localStorage.
